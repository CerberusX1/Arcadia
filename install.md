# Installing The Arcadia List AE

> **This list requires 280 GB of disk space.**

{% include fallout4-clean-install.md %}

### Step 2: Make sure you own all DLC and Creation Club content

You **must** own all DLC and Creation Club content included with the Anniversary Edition update. Launch Fallout 4 and download them.

### Step 3: Install the modlist

Open Wabbajack, find The Arcadia List AE under the Fallout 4 modlists, and install it. For detailed steps, see [Installing the List]({{ '/arcadia-list-ae/getting-started/' | relative_url }}#installing-the-list) in the Getting Started guide.

### Step 4: Play and enjoy

Launch the game through MO2 (use **F4SE**, not the regular game executable) and choose your profile. Not sure which one? See [Choosing a Profile]({{ '/arcadia-list-ae/getting-started/' | relative_url }}#choosing-a-profile-normal-vs-survival).
