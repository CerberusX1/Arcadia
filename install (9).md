# Installing Arcadia Sands

Watch the install video: <https://www.youtube.com/watch?v=t1L9nbQ8wHg>

{% include fallout4-clean-install.md %}

### Step 2: Make sure you own all DLC and Creation Club content

You **must** own all DLC and Creation Club content included with the Anniversary Edition update. Launch Fallout 4 and download them.

### Step 3: Install the modlist

Open Wabbajack, find Arcadia Sands under the Fallout 4 modlists, and install it.

### Step 4: Launch MO2 and play

Launch Mod Organizer 2, make sure the profile you want (Standard or Survival) is selected, and play.

## Next steps

Read [The Player's Handbook for Arcadia Sands]({{ '/sands/getting-started/' | relative_url }}) before your first launch. It explains how to choose between the Standard and Survival profiles.
