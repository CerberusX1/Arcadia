# Installing Dreadfall

{% include fallout4-clean-install.md %}

### Step 2: Make sure you own all DLC and Creation Club content

You **must** own all DLC and Creation Club content included with the Anniversary Edition update. Launch Fallout 4 and download them.

### Step 3: Install the modlist

Open Wabbajack, find Dreadfall under the Fallout 4 modlists, and install it. For detailed steps, see [Installing the List]({{ '/dreadfall/getting-started/' | relative_url }}#installing-the-list) in the Getting Started guide.

### Step 4: Launch MO2 and play

Launch Mod Organizer 2 and play using **F4SE**, not the regular game executable.

## Next steps
